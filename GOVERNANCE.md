# Governance

Service Compass is maintained by Codelitz Labs. Maintainers review contributions, set release scope, and merge changes.

Technical decisions should be discussed transparently through GitHub issues or Discussions. Maintainers evaluate proposals based on maintainability, security, usability, compatibility, and alignment with the project's focused engineering-context scope.

Contributors are encouraged to explain tradeoffs and participate in reviews. Maintainers make final decisions when consensus is not available and should document significant decisions.

This lightweight model is intended for the project's early open-source stage. More formal governance may be introduced as the contributor community and maintainer group grow.
