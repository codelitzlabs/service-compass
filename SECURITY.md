# Security policy

## Supported versions

Service Compass is in an early open-source stage and has not yet published a supported stable release. Security fixes are applied to the latest code on the default branch. After releases begin, this table must be updated with explicit supported versions.

| Version | Supported |
| --- | --- |
| Unreleased/default branch | Yes |
| Published versions | None yet |

## Report a vulnerability

Do not report suspected vulnerabilities in a public GitHub issue, discussion, pull request, log, or screenshot.

Use GitHub private vulnerability reporting when it is enabled. If it is unavailable, contact `opensource@codelitz.com`.

> **Maintainer verification required:** confirm that `opensource@codelitz.com` is monitored before publication, or replace it with a verified private security contact.

Include:

- affected version, commit, or deployment mode
- vulnerability type and affected component
- reproducible steps or a minimal proof of concept
- impact and any known prerequisites
- suggested mitigation, if available
- a safe way to contact the reporter

Do not include real secrets, credentials, customer data, internal URLs, or production configuration. Use redacted or fictional examples.

Please allow maintainers a reasonable opportunity to investigate and coordinate a fix before public disclosure. Avoid accessing unrelated data, degrading systems, or expanding testing beyond what is necessary to demonstrate the issue. The project does not currently promise a fixed response or remediation time.
